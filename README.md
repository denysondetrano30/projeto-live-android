# Projeto Live — Câmera Android

App de câmera do Projeto Live para Android 8 ou mais novo. Faz o mesmo que o app do iPhone:
manda imagem (Full HD, 30 qps) e som para a fonte "Celular (Projeto Live)" do OBS pelo Wi-Fi
(SRT), com a sincronia automática, a borda de "no ar", os avisos do diretor e o intercom.

O `.apk` sai pronto na aba **Actions** do GitHub (artefato `ProjetoLive-apk-<número>`).
Ele é assinado com uma chave de teste (pública, em `keystore/`), para poder atualizar o app
por cima sem desinstalar.
